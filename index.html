SkillBridge

Peer-to-peer skill exchange platform for university students to learn and teach micro-skills.

Features

  • 📣
    Micro-skill posting
    Allow users to create and publish listings for their micro-skills, including descriptions, pricing, and availability
  • 🔍
    Skill search and filtering
    Enable users to search for and filter micro-skills by category, price, and rating, with features like autocomplete and suggested skills
  • 💸
    Session booking and payment processing
    Integrate a secure payment system to facilitate transactions between users, with features like invoicing, payment tracking, and dispute resolution
  • 👍
    User rating and review system
    Develop a system for users to rate and review each other after sessions, with features like anonymous feedback, rating averages, and review moderation
  • 📅
    Session scheduling and reminders
    Allow users to schedule sessions and receive reminders and notifications, with features like calendar integration and customizable notification settings
