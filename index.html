SkillBridge

A peer-to-peer skill exchange platform that connects university students for 1-on-1 paid sessions to learn and teach micro-skills.

Features

  • 📝

    Micro-skill Posting

    Allow users to create and post micro-skills they can teach or want to learn.

  • 🔍

    Search and Filtering

    Enable users to search for micro-skills by keyword, category, or tag, and filter results.

  • 👥

    User Profiles and Reviews

    Create user profiles to display their posted micro-skills, reviews, and ratings.

  • 📅

    Booking and Scheduling

    Develop a system for users to book and schedule 1-on-1 sessions with each other.

  • 💸

    Secure Payment Processing

    Integrate a secure payment gateway to facilitate transactions between users.

  • 📊

    Session Management

    Allow users to manage their upcoming and past sessions.

  • 🔔

    Notification System

    Implement a notification system to inform users of new bookings and session reminders.
